# To do app

This simple app allows you to add to-do items.

You can assign a priority tag, color, due date and emoji to each to-do item.

### Testing notes

* Your to-do items will be stored in your browser.  
* You can filter items by their priority tag.  
* You can modify the title and description of your to-do list

### Stack

Made in Vanilla JS with the use of:

* [AirDatePicker](http://AirDatePicker)  
* [Tailwind](https://tailwindcss.com/)   
* [Hyper UI](https://www.hyperui.dev/)
